# 业务域名、CNAME 与地区调度

更新时间：2026-10-19

## 数据路径

业务项目使用业务域名访问 HTTPS。业务域名的 CNAME 指向中台生成的 `ct-<绑定 ID>.tunnel.<解析区域>`，目标记录通过华为云 `default_view` 指向国内节点，通过 `Abroad` 指向国际节点。所有其他地区自然回退到默认线路。控制面板负责 DNS 配置和校验，业务流量始终经过节点上的 HTTPS 入口和所绑定的数据通道。

TLS 的 Host / SNI 仍为业务域名，而非 CNAME 目标。发布时控制端直接连接两个节点的真实地址，以业务域名完成公开证书和 TLS 1.3 验证，校验证书有效期超过一天。CNAME 目标作为 DNS 调度名称，不需要额外申请入口证书。数据通道内部的 SNI / 工作区证书与业务 HTTPS 证书分别管理。

## 接入方式

1. 在 `dns.chitanda.net` 建立专用 API 用户，只授予需要的域名区域权限。现有华为云 AK / SK 保留在 DNS Manager，管理员无需开启 API 权限。
2. 在中台系统设置的“域名接入与地区调度”中保存 HTTPS 根地址、用户 ID、API 密钥、区域 ID 和区域域名。保存前检查区域及默认 / 境外线路。
3. 绑定一个业务域名及对应的国内、国际线路。两条线路源节点须已配置相同的 HTTPS 入口域名。此功能接管已有入口的 DNS 调度，不会凭空创建新的业务适配器、开放任意目标或绕过原有逐跳鉴权。
4. 点击“预览 / 校验”，核对三个目标记录及真实 SSL 校验结果，再点击“发布解析”。通道卡片下方展示业务域名、CNAME 目标及地区。

专用 API 连接写入 `CT_DATA/dns-provider.json`，权限 0600。快照和浏览器只返回连接元数据，不返回 API 密钥；节点配置中不包含 DNS 凭据。更新连接时留空密钥会保留已保存的值。

既有证书申请、续期和节点部署任务继续由 DNS Manager 管理。中台不会读取所有证书私钥，也不会通过普通域名 API 用户访问证书订单。新增业务入口应先完成节点侧的 HTTPS / 适配器配置和公开证书部署，再进行域名绑定。

## DNS 写入与回退

- 新绑定只允许接管与所选节点地址、地区完全一致的旧 A 记录。其他 TXT、AAAA、CNAME 或其他业务记录会导致预览停止，不会被覆盖。
- 预览有五分钟有效期，发布前重新验证 SSL、节点与 DNS 指纹；状态变化后必须重新预览。
- 初次接入先创建两个地区目标 A 记录，再把业务域名的旧 A 记录替换为 CNAME。已有目标地址变化使用原记录 ID 原地更新。
- 每次发布前在 `CT_DATA/dns-backup-<ID>-<时间>.json` 保存原记录。失败时重新读取实际 DNS 状态并与快照对齐，涵盖“服务端已执行但响应丢失”的情况；回退未能完成时明确标记错误。
- 已发布绑定不提供直接删除按钮，以免移除生产解析。移除业务时应先恢复或迁移其接入记录，核对两地实际请求，再进行运维清理。
- 当前按管理员选择的线路执行预览和发布，不自动进行跨节点容灾切换。节点地址改变后重新预览并发布。

## 发布与验证

控制端 2.8.0 与现有 2.7.0 节点兼容，节点、线路版本及业务身份无需修改。只增量发布控制端模块、面板静态文件及版本文件，保留账号、CA、节点令牌和工作区状态。

`npm test` 包含 DNS 接管范围、预览指纹、原地更新、失败回退及密钥不回显测试；`npm run test:ui` 检查既有页面和证书设置回归。每次修改后同步日志并推送 GitHub，生产 DNS 快照和凭据留在服务器私有目录。
