控制面板 2.14.2，节点 2.8.1。此记录只保留配置与测试结论，不包含节点凭据、业务密钥或 SSH 身份。

## 实际路径

- 国内节点：110.42.98.254。
- 第一段优化机：47.243.148.109。
- 第二段优化机 / 可兼任终点：154.12.176.212（amd64，登记身份保持不变）。
- 国际端：170.9.59.149（ARM64）。
- 国内杜甫 110.42.32.161 继续提供控制面及既有国内业务，不作为新增四机路径的中间节点。

两台新增机器先分别作为独立国际端，经香港优化机验证三机路径；154 随后切换为第二段优化机，并保留在三机路径中兼任终点。

## 数据与故障

| 验证 | 结果 |
| --- | --- |
| 国内 ↔ 香港 ↔ 154 与国内 ↔ 香港 ↔ 170 两条路径共用优化机 | H2 / H3 / Stream 双向通过 |
| 国内 ↔ 香港 ↔ 154 ↔ 170 两段优化机串联 | H2 / H3 / Stream 双向通过 |
| 每个方向、协议、目标并发 4 次，每次 256 KiB | 共 72 次、18 MiB，核对目标标签、长度及 SHA-256 均一致 |
| 停止 154 节点 | 三种协议串联路径均失败，不跳过中间节点；独立香港至 170 路径继续成功 |
| 重启 154 节点 | 三种协议恢复，不重启其他节点；本次约一分钟内完成检查 |
| 既有业务 URL 两端调用 | 国内和 168 源站均返回 200，TLS 1.3 |

故障测试发现并修复了 H3 旧复用会话在中间节点重启后持续超时的问题。节点探测失败时只淘汰对应会话，由后续控制周期按已授权配置重建；控制端暂不可达时也保留该恢复逻辑。升级和配置同步期间仍会出现短暂不可用；此验证不代表无中断切换或吞吐性能基准。

- 58 项后端检查通过，包括多段最小权限、相邻凭据隔离、双向路径反转、无效编辑原子回退和中间节点关联保护。

- 8 种 Linux 架构程序交叉编译、摘要及大小校验完成；新增实机涵盖 amd64 / ARM64。未重复执行与本次变更无关的全部发行版安装矩阵。
