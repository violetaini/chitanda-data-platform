# 删除数据通道

2.16.1 起，每张卡片右上角常驻“删除”，无需展开详情。点击后显示确认窗口，列出通道名称、删除方向数量和关联域名；取消不改变配置。

- 未绑定域名：确认后删除该通道及全部方向。
- 仅有未发布且没有发布错误的域名草稿：同时清理本通道草稿，不改动其他绑定和外部 DNS。
- 已发布、存在历史发布时间或发布错误尚未核实：明确提示先迁移或核验绑定，后端仍返回 409，避免遗留生产解析指向已删除通道。

隔离测试覆盖确认删除、取消、草稿关联清理、双向原子删除、保留其他通道及发布保护。63 个后端测试、98 项隧道/账户界面检查通过。上线时保留生产状态、账户、CA 和管理 ACL。
