# 2.9.0 隧道与个人设置验收

验收日期：2026-10-19（UTC+8）。

## 功能及回归

- 创建隧道可选单向或双向；双向在一张卡片中管理互为反向的两个方向，端口可分别设置，分别测活，统一启停及编辑。
- 业务域名、CNAME、地区入口、DNS 预览及发布均位于隧道卡片。系统设置只保留 DNS 管理连接。
- 单向 DNS 只发布默认线路的一条目标 A 记录，全部地区回退到同一个入口 IP；双向发布国内默认及国际境外两条目标 A 记录。
- `npm test`：35 项通过，涵盖旧绑定合并、原子保存、端口冲突回退、方向与凭据边界、DNS 记录及失败回退。
- `npm run test:ui`：6 个脚本、168 项检查通过；新增场景使用真实本地 API，验证单双向创建、隧道内绑定、双向启停和旧 API 禁止单边修改。测试使用隔离状态，不改生产业务数据。
- 个人设置在 1680、1200、390px 视口铺满可用主内容宽度，无横向溢出；隧道页面在 1680、1024、390px 视口无横向溢出，并已检查截图。
- 每个方向保留 H2 / H3 / Stream 协议标识；该显示调整后的隧道与个人设置 UI 检查再次通过。
