# SSL 证书的三种来源

先在“系统设置 → SSL 证书”添加根域名，再点击“选择证书”配置来源。同一根域名只保留一份配置；选定后“维护证书”保持当前来源，其他来源只能通过“切换模式”替换，不并存。根域名不可直接改名，不接受重复或重叠的管理范围。

三种来源都只接受 SAN 明确包含 `*.根域名` 的泛域名证书，单域名证书不能保存或下发。系统设置仅显示根域名、泛域名证书有效性、根域名覆盖情况及到期日；节点实际加载状况在节点管理简要显示。SNI 仍在隧道中设置，内部身份保持默认机制。

## 自动申请与续签

中台通过 Let’s Encrypt ACME DNS-01 申请公网证书。连接 DNS Manager 签名 API，为所属区域的根域名选择自动模式并同意 CA 条款；自动申请根域名和对应泛域名。通知邮箱可选。中台保存独立 ACME 账户，私钥仅存于私有数据目录，使用已有 Node.js / OpenSSL 环境，无需节点安装申请程序。

每小时检查有效期，默认提前 30 天续签，可设置 7–60 天。验证记录使用 TXT，签发后仅移除本次生成的值，保留其他记录值。DNS 面板返回带引号 TXT 时也可清理；失败保存私有重试日志并在后续任务补清理。网络请求及 nonce 错误有有限重试；失败保留现有证书。

自动模式不覆盖已有验证 CNAME。存在其他验证委托时，应按实际 DNS 布局配置，或使用已有 DNS 面板续签模式。

## DNS 面板续签并同步

选择 DNS 面板模式后，从列表选择证书。列表只包含已授权、有效且匹配当前根域名的泛域名证书，不再手填订单 ID。DNS 面板负责申请、续签和自己的自动任务；中台每 60 秒检查选中订单。只有证书或私钥变化才增加节点配置版本。读取失败、证书不匹配或同一来源的证书回退时保留现有证书并重试。管理员显式切换来源或证书订单可替换为另一份通过验证的证书。

连接使用系统设置已有的 DNS API 地址和身份。上游管理员 API 支持 `/api/cert/order`；受限账号建议部署仓库的 [指定订单导出组件](../integrations/dns-manager-certificate-export.php)：

1. 将组件安装为 DNS Manager 的 `app/controller/DatahubCertificate.php`。
2. 在 `route/app.php` 的现有 `AuthApi` 路由组内添加 `Route::post('/cert/datahub/order', 'datahubCertificate/order');` 及 `Route::post('/cert/datahub/list', 'datahubCertificate/catalog');`。
3. 在程序根目录 `config/datahub-certificate-scopes.json` 配置受限 API 用户可读的订单 ID，例如 `{"users":{"123":[1,2]}}`。文件由管理员维护，置于网站 public 目录外，建议 root 所有、PHP 运行组可读、0640。保留现有 PHP open_basedir 限制。

组件保留原签名认证，仅导出明确授权且已签发的订单，不给受限用户管理员权限。列表接口只返回证书公开元数据，不含证书链或私钥；后台读取选定证书时优先调用导出接口，再兼容原管理员接口。DNS 系统升级后需保留组件与路由；新增订单需管理员显式授权。

## 自行上传与维护

可选择证书链文件和私钥文件，也可粘贴 PEM。保存时验证泛域名 SAN、完整链、有效期、入口域名和密钥匹配，校验失败不替换原配置。到期前自行续签，再上传新文件。维护或切换时两项均留空可保留现有的合格泛域名证书，私钥不回显。泛域名不自动覆盖根域名本身，卡片会标明根域名是否包含在证书中。

## 下发与加载

首次配置来源时，将当前已有且入口域名匹配的节点登记为使用此根域名证书。已有部署迁移时保留当前节点的授权；新节点在“节点管理 → 编辑节点 → SSL 证书根域名”选择后接收证书。节点自行上报某个域名不能获得对应私钥，节点权限绑定只能由管理员修改。泛域名只覆盖一层子域名，多层子域不会自动匹配。

三种来源统一通过节点原有认证配置下发，正常同步约 15 秒。内置 HTTPS 入口在内存中热更新；外置 Nginx 入口原子写入单个 0600 PEM bundle，由已有固定本机服务执行配置检查与重载，通常再等最多约 15 秒。

节点卡片根据真实加载证书显示有效、即将到期、已过期、待更新或离线；不把对端握手证书当成本节点证书。外部系统暂不可用时可继续使用上次证书。移除根域名恢复相关节点原有备用证书源；其有效性仍由本机维护。无需重置节点身份、隧道令牌或重建业务通道。

公网证书与节点内部身份不同：原生 Stream 不使用 TLS 证书；H2/H3 节点身份默认沿用工作空间证书。业务源站网站的证书和管理面板网站证书仍由各自部署管理。
